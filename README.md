## 🌟 О проекте

Персональное **портфолио-игротека** в пиксельно-неоновом стиле.
Внутри: **6 полноценных игр**, глобальный музыкальный плеер, система достижений, две темы, форма связи и куча интерактива.

Всё работает **без сервера**, **без базы данных**, **без фреймворков** — только чистый код, который ты можешь читать и учиться.
